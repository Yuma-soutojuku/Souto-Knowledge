## 問題8：3次方程式の実数解の個数と領域

**【解答・解説】**
$f(x) = 2x^3 - 3ax^2 + 2b$ とおきます。
微分すると $f'(x) = 6x^2 - 6ax = 6x(x-a)$ となり、$x=0$ または $x=a$ で $f'(x)=0$ となります。
方程式が異なる3つの実数解をもつための条件は、極値をもち、かつ **（極大値）$\times$（極小値）$< 0$** となることです。
極値をもつためには $a \neq 0$ が必要です。

$f(0)$ と $f(a)$ の積が負であればよいので、


$$f(0)f(a) = (2b)(2a^3 - 3a^3 + 2b) = 2b(-a^3 + 2b) < 0$$


両辺を2で割って整理すると、


$$b \left( b - \frac{1}{2}a^3 \right) < 0$$

この不等式が表す領域は、$ab$ 平面上において以下のようになります。

* $a > 0$ のとき： $0 < b < \frac{1}{2}a^3$
* $a < 0$ のとき： $\frac{1}{2}a^3 < b < 0$

**【答え】**
領域は、曲線 $b = \frac{1}{2}a^3$ と $a$ 軸（$b=0$）で囲まれた部分です。（境界線はすべて含まない）

## 問題9：3次方程式の解の個数の場合分け

**【解答・解説】**
$f(x) = x^3 + 3ax^2 + 3ax + a^3$ とおきます。
$f'(x) = 3(x^2 + 2ax + a)$ となり、$f'(x)=0$ の判別式を $D$ とすると、


$$\frac{D}{4} = a^2 - a = a(a-1)$$


**① 極値をもたない場合（$0 \leqq a \leqq 1$ のとき）**
$f'(x) \geqq 0$ となり、$f(x)$ は単調増加します。実数解は **1個** です。

**② 極値をもつ場合（$a < 0$ または $a > 1$ のとき）**
$f'(x)=0$ の2つの解を $\alpha, \beta$ とすると、解と係数の関係より $\alpha+\beta = -2a, \alpha\beta = a$ です。
$f(x)$ を $\frac{1}{3}f'(x)$ すなわち $x^2 + 2ax + a$ で割ると、商が $x+a$、余りが $-2a(a-1)x + a^2(a-1)$ となります。
$f(\alpha) = -2a(a-1)\alpha + a^2(a-1)$ となるため、極値の積は以下のように計算できます。


$$f(\alpha)f(\beta) = a^2(a-1)^2 (2\alpha - a)(2\beta - a)$$

$$= a^2(a-1)^2 \{4\alpha\beta - 2a(\alpha+\beta) + a^2\}$$

$$= a^2(a-1)^2 \{4a - 2a(-2a) + a^2\} = a^3(a-1)^2(5a+4)$$

ここで、すでに $a < 0$ または $a > 1$ であるため、$(a-1)^2 > 0$ は確定です。符号は $a^3(5a+4)$ で決まります。

* $a > 1$ のとき： $a^3(5a+4) > 0$ （極値が同符号） $\implies$ 実数解は **1個**
* $a = -\frac{4}{5}$ のとき： 極値の積が $0$ $\implies$ 実数解は **2個**
* $-\frac{4}{5} < a < 0$ のとき： 極値の積が負 $\implies$ 実数解は **3個**
* $a < -\frac{4}{5}$ のとき： 極値の積が正 $\implies$ 実数解は **1個**

**【答え】**

* $a < -\frac{4}{5},\ 0 \leqq a$ のとき： 1個
* $a = -\frac{4}{5}$ のとき： 2個
* $-\frac{4}{5} < a < 0$ のとき： 3個

## 問題10：対称式と3変数の最大最小

**【解答・解説】**
**(1) $z$ のとりうる値の範囲**
$x+y = 2-z$
$xy = 1 - z(x+y) = 1 - z(2-z) = z^2 - 2z + 1$
$x, y$ は実数なので、2次方程式 $t^2 - (2-z)t + (z^2-2z+1) = 0$ は実数解をもちます。判別式 $D \geqq 0$ より、


$$D = (2-z)^2 - 4(z^2-2z+1) = -3z^2 + 4z \geqq 0$$

$$z(3z - 4) \leqq 0 \implies 0 \leqq z \leqq \frac{4}{3}$$

**(2) $xyz$ を $z$ の式で表す**


$$xyz = z(xy) = z(z^2 - 2z + 1) = z^3 - 2z^2 + z$$

**(3) $xyz$ の最小値と $x,y,z$**
$f(z) = z^3 - 2z^2 + z \ (0 \leqq z \leqq \frac{4}{3})$ とおきます。
$f'(z) = 3z^2 - 4z + 1 = (3z-1)(z-1)$
$z = \frac{1}{3}, 1$ で極値をもちます。範囲内の値を調べると、
$f(0)=0,\ f\left(\frac{1}{3}\right)=\frac{4}{27},\ f(1)=0,\ f\left(\frac{4}{3}\right)=\frac{4}{27}$
したがって最小値は $0$ です（$z=0, 1$ のとき）。

* $z=0$ のとき： $t^2 - 2t + 1 = 0 \implies t=1$ より $x=y=1$
* $z=1$ のとき： $t^2 - t = 0 \implies t=0, 1$ より $(x,y)=(0,1), (1,0)$

**【答え】**
(1) $0 \leqq z \leqq \frac{4}{3}$
(2) $xyz = z^3 - 2z^2 + z$
(3) 最小値 **$0$**。そのときの値は **$(x, y, z) = (1, 1, 0), (1, 0, 1), (0, 1, 1)$**

## 問題11：方程式の解の存在範囲と定数分離

**【解答・解説】**
方程式を $b = -x^3 + 3a^2x$ と変形し、$f(x) = -x^3 + 3a^2x$ とおきます。
$0 \leqq x \leqq 1$ の範囲で、直線 $y=b$ と曲線 $y=f(x)$ が共有点をもつ $b$ の条件を求めます。
$f'(x) = -3x^2 + 3a^2 = -3(x-a)(x+a)$。$a \geqq 0$ より $x \geqq 0$ の範囲では $x=a$ で極大値 $2a^3$ をとります。

* **$0 \leqq a \leqq 1$ のとき：** $0 \leqq x \leqq 1$ に極大値が含まれます。
最大値は $f(a) = 2a^3$。最小値は $f(0)=0$ か $f(1)=3a^2-1$ の小さい方です。
よって、$a < \frac{1}{\sqrt{3}}$ のときは $3a^2 - 1 \leqq b \leqq 2a^3$。
$\frac{1}{\sqrt{3}} \leqq a \leqq 1$ のときは $0 \leqq b \leqq 2a^3$ となります。
* **$a > 1$ のとき：** 区間内で $f(x)$ は単調増加します。
最小値は $f(0)=0$、最大値は $f(1)=3a^2-1$ です。
よって、$0 \leqq b \leqq 3a^2 - 1$ となります。

**【答え】**
$ab$ 平面上の領域は以下の不等式で表される範囲です（境界線を含む）。

* $0 \leqq a \leqq \frac{1}{\sqrt{3}}$ のとき： $3a^2 - 1 \leqq b \leqq 2a^3$
* $\frac{1}{\sqrt{3}} < a \leqq 1$ のとき： $0 \leqq b \leqq 2a^3$
* $a > 1$ のとき： $0 \leqq b \leqq 3a^2 - 1$

## 問題12：曲線外の点から引ける接線の本数

**【解答・解説】**
接点を $(t, t^3-at^2)$ とおくと、接線の方程式は


$$y - (t^3 - at^2) = (3t^2 - 2at)(x - t)$$


これが $(1, 0)$ を通るので、代入して整理すると $t$ の3次方程式になります。


$$-t^3 + at^2 = (3t^2 - 2at)(1 - t)$$

$$2t^3 - (a+3)t^2 + 2at = 0$$

$$t \{ 2t^2 - (a+3)t + 2a \} = 0$$


接線がちょうど2本存在するには、この3次方程式が「ちょうど2つの実数解」をもてばよいです。
$t=0$ 以外の2次方程式部分 $g(t) = 2t^2 - (a+3)t + 2a = 0$ について、

1. **$g(t)=0$ が $t=0$ を解にもつ場合：** $g(0) = 2a = 0 \implies a = 0$。このとき $g(t) = 2t^2-3t$ で解は $0, \frac{3}{2}$（2重解と異なる解となり条件を満たす）。
2. **$g(t)=0$ が $t \neq 0$ の重解をもつ場合：** 判別式 $D = (a+3)^2 - 16a = a^2 - 10a + 9 = 0 \implies a = 1, 9$。

接線の方程式は求めた $a$ と接点 $t$ からそれぞれ計算します。
**【答え】**

* **$a=0$** のとき：接線 $y=0,\ y=\frac{27}{4}x - \frac{27}{4}$
* **$a=1$** のとき：接線 $y=0,\ y=x-1$
* **$a=9$** のとき：接線 $y=0,\ y=-27x+27$

## 問題13：直交する2本の接線

**【解答・解説】**
接点を $(t, t^3-t)$ とおくと、接線は $y = (3t^2-1)(x-t) + t^3-t$。これが $(a, b)$ を通るので、


$$2t^3 - 3at^2 + a + b = 0$$


これがちょうど2つの実数解（重解）をもつので、$h(t) = 2t^3 - 3at^2 + a + b$ が $t=0$ または $t=a$ で極値 $0$ をとります。

* $h(0) = a+b = 0 \implies b = -a$
* $h(a) = -a^3+a+b = 0 \implies b = a^3 - a$

**ケース1：$b = -a$ のとき**
方程式は $t^2(2t - 3a) = 0$ となり、接点は $t=0, \frac{3a}{2}$。
それぞれの接線の傾きは $m_1 = -1$、$m_2 = 3(\frac{3a}{2})^2 - 1 = \frac{27a^2}{4} - 1$ です。
直交条件 $m_1 m_2 = -1$ より、$-1 \cdot (\frac{27a^2}{4} - 1) = -1 \implies \frac{27a^2}{4} = 2 \implies a^2 = \frac{8}{27}$。
$a = \pm \frac{2\sqrt{6}}{9}$ となり、実数解として適します。

**ケース2：$b = a^3 - a$ のとき**
方程式は $(t-a)^2(2t+a) = 0$ となり、接点は $t=a, -\frac{a}{2}$。
傾きの積の直交条件を解くと $9a^4 - 15a^2 + 8 = 0$ となりますが、判別式が負（$15^2 - 4\cdot 9\cdot 8 = 225 - 288 < 0$）となり、これを満たす実数 $a$ は存在しません。

**【答え】**
$(a, b) = \left( \frac{2\sqrt{6}}{9}, -\frac{2\sqrt{6}}{9} \right),\ \left( -\frac{2\sqrt{6}}{9}, \frac{2\sqrt{6}}{9} \right)$

## 問題14：接線が3本引けるためのパラメータの範囲

**【解答・解説】**
接点を $(k, k^3-k^2)$ とおいて接線を立て、$(1, t)$ を代入して整理すると、問題12等と同様に以下の3次方程式を得ます。


$$2k^3 - 4k^2 + 2k + t = 0$$


接線が3本引けるということは、この $k$ についての方程式が異なる3つの実数解をもつことです。
$g(k) = 2k^3 - 4k^2 + 2k + t$ とおくと、$g'(k) = 6k^2 - 8k + 2 = 2(3k-1)(k-1)$ より $k=\frac{1}{3}, 1$ で極値をもちます。
異なる3つの実数解をもつ条件は $g(\frac{1}{3})g(1) < 0$ です。
$g(1) = t$
$g(\frac{1}{3}) = 2(\frac{1}{27}) - 4(\frac{1}{9}) + 2(\frac{1}{3}) + t = t + \frac{8}{27}$
よって $t \left( t + \frac{8}{27} \right) < 0$ となります。

**【答え】**
$-\frac{8}{27} < t < 0$

## 問題15：接線が3本引ける領域の図示

**【解答・解説】**
解説にある通り、$g(t) = 2t^3 - 3Xt^2 + X + Y$ とおき、$g(t)=0$ が異なる3つの実数解をもつ条件を求めます。
$g'(t) = 6t(t - X)$ となるため、$X \neq 0$ かつ 極値の積 $g(0)g(X) < 0$ が条件です。


$$g(0)g(X) = (X+Y)(-X^3+X+Y) < 0$$


これを満たす領域は、直線 $Y = -X$ と 曲線 $Y = X^3 - X$ の大小関係が入れ替わる部分です。すなわち、

* $Y > -X$ かつ $Y < X^3 - X$
* $Y < -X$ かつ $Y > X^3 - X$
のいずれかを満たす領域となります。

**【答え】**
$xy$ 座標平面において、曲線 $y = x^3 - x$ と直線 $y = -x$ によって分割される領域のうち、**上下の大小関係が $y = -x$ と $y = x^3 - x$ の間にある部分**（境界線はすべて含まない）。
